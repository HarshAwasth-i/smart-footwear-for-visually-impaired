# Smart Footwear for Visually Impaired

📌 Overview
This project helps visually impaired people detect obstacles using sensors embedded in footwear.

🎯 Problem Statement
Visually impaired people face difficulty in navigating safely.

💡 Solution
Smart footwear with sensors that detect obstacles and alert the user.

 ⚙️ Technologies Used
- Sensors (Ultrasonic)
- Microcontroller (Arduino)
- Machine Learning 

 🚀 Features
- Obstacle detection
- Audio/Vibration alert
- Lightweight design

 📊 Future Scope
- GPS integration
- Mobile app connectivity

It helps people in navigating in better way
